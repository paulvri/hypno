# Слои восприятия

Интерактивная визуализация трёх слоёв восприятия в одном файле — `index.html`
(WebGL2, без зависимостей и сборки).

## Запуск

- Откройте `index.html` двойным кликом в Chrome, Edge, Firefox или Safari; или
- запустите `python3 -m http.server 8000` и откройте http://localhost:8000.

## Слои

Всё показанное — внутреннее видение: глаза закрыты, темнота, как под маской для сна.

- **I · Туман на стекле** — прозрачное стекло, на котором туман сам «рисует»
  знакомые образы (Орион, Стрелец, лица, цифры, животные). Кривые проходят
  через цветные точки-камни, но не прямыми отрезками, а по контуру образа.
- **II · Капсула / эпифиз** — вид изнутри яйца из кожи с сосудами, с острого
  конца. Капсула целиком заполнена абсолютно прозрачной водой — воздуха нет.
  Вы — источник света; тёплая вода чуть колышется, поэтому дальние стенки слегка
  дрожат, а по поверхностям плывёт тонкая световая сетка. Глянцевые вертикальные
  гофрированные трубки-«бусины»: фиолетовые и тонкие белые («незрелые»), гофра
  бежит сверху вниз. Под сводом кристаллизуется друза, плавно тонет, ложится на
  дно и растворяется — цикл около 40 с.
- **III · Гипнагогия** — плоское «кино» засыпания: тоннель, соты, лицо в облаках,
  закат, коридор, спираль, полёт, глаз, огни.

## Режимы (клавиши 1–4)

1. **Стопка стёкол** — три прозрачных экрана на луче взгляда в пространстве.
   Тяните — облёт, клик по слою — фокус, двойной клик — глазами наблюдателя,
   ползунок сводит слои в одну картину.
2. **Погружение** — от первого лица: сквозь стекло → в капсулу → через дальнюю
   стенку в плоский сон. Колесо / ↑↓ — глубина, мышь — взгляд.
3. **Засыпание** — глаза закрыты, маска для сна, темнота: слои сменяют друг друга
   по мере засыпания — искорки и туманные образы → внутренний свет капсулы →
   тоннели и спирали → гипнагогия. Удерживайте пробел или кнопку мыши — глубже в сон.
4. **Линза внимания** — все слои в одной плоскости, внимание прорезает их линзой.

`H` — скрыть интерфейс, `F` — полный экран (также кнопки в правом верхнем углу).

## Телефоны и планшеты

Работает в Safari (iOS/iPadOS 15+) и Chrome/Samsung Internet (Android) в портретной
и альбомной ориентации: интерфейс перестраивается под экран, учитывает вырезы
(safe area), настройки открываются кнопкой-ползунками. Жесты: провести — облёт /
глубина, щипок — масштаб / размер линзы, двойной тап — «глазами наблюдателя»,
удержание — глубже в сон. Качество подстраивается под частоту кадров; вручную —
параметр `?q=0.5`.

## Telegram

Встроенный просмотр файлов Telegram на iPhone и iPad (как и «Почта» и «Файлы»)
намеренно не выполняет JavaScript, поэтому анимация внутри него не запускается —
вместо чёрного экрана показывается подсказка. Откройте файл через «Поделиться» в
браузере (Яндекс Браузер, Chrome, Safari). Ссылки на размещённую страницу Telegram
открывает во встроенном браузере — там JavaScript работает.
